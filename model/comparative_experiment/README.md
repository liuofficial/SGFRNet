# Comparison models

This directory contains the source implementations retained from the original comparison experiments:

- ALCNet
- BGM
- DCANet
- DSTransNet and its local dependencies
- DWTFreqNet and decoder-fusion components
- EGPNet
- HDNet
- MSDANet
- RPCANet
- SCTransNet

Install `requirements-comparison.txt` from the repository root before importing these modules. Pretrained weights, TensorBoard events, metric logs, and Python bytecode are deliberately excluded from the code release.
